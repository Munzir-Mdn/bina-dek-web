Bagaimana data sampai ke destinasi?

Model OSI membahagikan komunikasi rangkaian kepada tujuh lapisan supaya setiap fungsi lebih mudah difahami.

Lapisan 7 hingga 4

  1. L7 · Application

    Menyediakan perkhidmatan komunikasi kepada aplikasi.

  2. L6 · Presentation

    Mengurus representasi dan format data.

  3. L5 · Session

    Mengurus sesi komunikasi.

  4. L4 · Transport

    Mengurus pemindahan data antara sistem hujung.

Lapisan 3 hingga 1

  1. L3 · Network

    Mengurus penghantaran paket merentas rangkaian. IP ialah contoh.

  2. L2 · Data Link

    Mengurus penghantaran bingkai pada satu pautan. Ethernet ialah contoh lazim.

  3. L1 · Physical

    Menghantar bit sebagai isyarat melalui medium fizikal.

Alamat IP dan alamat MAC

  • IP · Contoh L3

    Penghala menggunakan maklumat IP untuk menentukan laluan paket ke rangkaian destinasi.

  • MAC · Contoh L2

    Alamat MAC destinasi pada bingkai Ethernet membantu menghantar bingkai pada pautan setempat.

Uji kefahaman
